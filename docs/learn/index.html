How to use the course

Take main lessons 1–11 in order on the first pass. Lessons 12–15 form the optional robot track. Follow the core explanation, predict before moving a control, then attempt the fresh problem. Optional notes preserve extra detail for a second pass. Plan around 15–20 minutes for a core path; allow longer for practice or optional reading. At each explain-back, ask the teaching agent to probe your reasoning and record demonstrated learning.

Part I · Seeing images as data

  1. Choose the vision taskInput, output, classification, detection, segmentation, and success.
  2. Images are dataPixels, channels, coordinates, tensor shapes, and transforms.
  3. Visual featuresColor, edges, filters, useful invariance, and shortcuts.

Part II · Learning visual representations

  1. How models learnExamples, targets, parameters, training, and inference.
  2. Loss and optimizationPrediction, error, gradient, learning rate, batch, and epoch.
  3. Generalization and data splitsOverfitting, validation, test discipline, leakage, and shift.
  4. Neural networks and convolutionsActivations, shared local filters, feature maps, and context.
  5. Transfer learning and augmentationPretraining, fine-tuning, label-preserving transformations, and rollback.

Part III · Evaluate and improve the detector

  1. Object detectionBoxes, candidates, scores, IoU, thresholding, and NMS.
  2. Evaluate a detectorMatching, TP/FP/FN, precision, recall, AP, and test matrices.
  3. Did fine-tuning help?Compare candidates fairly and finish with an experiment plan.
