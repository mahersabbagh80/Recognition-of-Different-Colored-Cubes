Questions at export time

  • Is the input shape static or dynamic?
  • Which ONNX opset and operators are used?
  • Is postprocessing inside or outside the exported graph?
  • Which precision is used, and how much numerical drift is acceptable?
  • Does the target TensorRT/CUDA/device combination match the built engine?

Verification rule

A structural ONNX check cannot prove live accuracy, and a random-input TensorRT benchmark cannot prove detector correctness. Validate structure, numerical behavior, deployment-domain behavior, and performance separately.
