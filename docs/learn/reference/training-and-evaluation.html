Learning loop

labelled batch → prediction → loss → gradients → optimizer update
validation split → checkpoint selection
untouched test or deployment gate → final evidence

The gradient describes how parameter changes affect loss. Gradient descent updates parameters in the direction intended to reduce that loss.

Metrics answer different questions

EvidenceWhat it can supportWhat it cannot support alone
Validation precision/recall/APPerformance on that labelled validation distribution.Reliable performance in a different room or camera domain.
Per-class frame-hit countWhether a predicted class ID appeared in expected frames.Ground-truth accuracy, recall, or AP.
Empty-scene keepsA specific false-positive rejection gate.Positive detection quality.
Latency and publish rateRuntime responsiveness under stated conditions.Detection correctness.

Improvement loop

  1. Define the failing gate.
  2. Localize the failing stage.
  3. Change one plausible cause.
  4. Repeat the same positive, negative, and runtime gates.
  5. Promote only after regression checks pass; preserve rollback.

Current boundary

M5 is PARTIAL: the runtime path operates and the recorded empty scene remains quiet, but reliable room-domain positive detection is not yet demonstrated.
