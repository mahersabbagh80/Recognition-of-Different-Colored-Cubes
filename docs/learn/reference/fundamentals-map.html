Five questions for any vision system

  1. What observation enters, in what representation?
  2. What output does the consumer actually need?
  3. Which examples change the model, guide choices, and measure it?
  4. Which transformations and runtime boundaries must preserve meaning?
  5. What measured evidence supports the deployment claim?
