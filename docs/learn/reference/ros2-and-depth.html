Depth vocabulary

Z-depth is distance along the camera’s optical axis. A closer raised surface normally has smaller z-depth than the floor behind it. Camera intrinsics convert pixel extent into an approximate physical extent only when depth and RGB coordinates are appropriately aligned.

Known code defect

The current predicate depth > floor + threshold selects farther pixels, not a closer raised top. Its KEEP/REJECT counts describe current software behavior, not validated physical height classification.
