Camera to model

  1. ROS image → OpenCV: `cv_bridge` produces an H×W×3 BGR array.
  2. Letterbox: resize without distorting aspect ratio, then add padding to reach 640×640.
  3. Color and layout: BGR → RGB, then HWC → CHW.
  4. Batch and units: add the batch axis and convert bytes to float32 values divided by 255.
camera: H × W × 3, uint8, BGR
model:  1 × 3 × 640 × 640, float32, RGB, values 0…1

Coordinates

RepresentationMeaning

Inverse letterbox

x_camera = (x_model - pad_x) / ratio
y_camera = (y_model - pad_y) / ratio
then clip to the original camera-frame width and height

Common failure

Transposing or reshaping changes organization, not physical units. Pixel coordinates do not become millimetres without depth, calibration, or another scale source.
