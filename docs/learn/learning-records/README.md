# Learning records

This directory is reserved for evidence of what Maher can use or explain—not for lesson coverage, workspace setup, or project activity logs.

Create `0001-<dash-case-name>.md` only after one of these events:

- Maher explains or applies a non-trivial concept correctly;
- Maher states prior knowledge with enough detail to guide future lessons;
- a misconception is corrected and the corrected model is demonstrated; or
- the learning mission changes because of what was learned.

Each record should state the demonstrated understanding, the evidence, and what it changes about the next lesson. Until the first such demonstration is assessed, the honest learning state is **not yet measured**.
