# ML and Computer Vision Learning Workspace

Open [`index.html`](index.html) in a browser to begin the eleven-lesson training course. Four additional lessons form an optional robot-integration track. Two [recovered workshops](index.html#recovered-workshops) add useful material from the original nine lessons; see the [recovery map](ARCHIVE-RECOVERY.md).

## Structure

- `MISSION.md` — the learning goal and constraints.
- `LESSON-PLAN.md` — the course sequence and completion criteria.
- `lessons/` — current interactive HTML lesson pages.
- `reference/` — compressed reference sheets.
- `RESOURCES.md` — curated primary and official sources.
- `VALIDATION.md` — structural, browser, theme, and evidence checks.
- `learning-records/` — demonstrated understanding and mission decisions.
- `assets/` — shared styles, scripts, and fonts.
- `archive/2026-09-07-project-first-course/` — recoverable snapshot of the superseded nine-lesson course.

Required exercises run in the browser. Python examples, where mentioned, are optional. Course pages use shared assets and work when opened locally.

The approved revision uses local definitions, worked examples, and several interactions per lesson. Shared controls provide theme switching, course navigation, references, and teaching-agent follow-up. Earlier PDFs remain under `output/pdf/`; regeneration is deferred at Maher's request.
