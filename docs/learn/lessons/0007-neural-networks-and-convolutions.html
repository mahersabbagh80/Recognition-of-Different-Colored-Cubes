1. A neural network is a layered computation

Look at a cube edge twice: once near the left border, once near the center. A useful image model should notice the same local pattern in both places, then combine many such responses into a larger shape.

A neural network is a layered computation made from connected units. A unit forms a weighted sum, adds a bias, and applies an activation function, a rule that reshapes the intermediate value before the next layer. For one unit, a = w×x + b; a is the pre-activation, x is an input feature, and w and b are adjustable parameters. A nonlinear activation lets layers express combinations that one straight weighted sum cannot.

ReLU means rectified linear unit. It returns the input when the input is positive and returns zero otherwise: ReLU(a) = max(0,a). The word max means choose the larger value. A negative signal is suppressed; a positive signal passes through unchanged. ReLU is a simple activation, not a claim that a feature is literally a neuron firing.

Central mental modelOne unit makes a score. An activation reshapes that score. Layers combine many activated features. Training changes the weights and biases so later outputs support the task.

Worked example: with input x = 2, weight w = −1, and bias b = 1, the pre-activation is a = (−1)×2 + 1 = −1. ReLU compares 0 and −1, so the output is 0. For a = 3, it compares 0 and 3, so the output is 3.

2. Why images need convolution

A pixel is one small image sample. A fully connected, or dense, layer gives each output unit a separate weight for every input number. It can work, but it ignores two useful image properties: nearby pixels often form meaningful local patterns, and the same edge or corner can appear in different positions.

A convolutional neural network, or CNN, uses layers that slide a small grid called a kernel across the input. Matching cells are multiplied and added to produce one response at each position. Reusing the same weights is weight sharing; the output grid is a feature map showing where that learned local pattern responds.

3. RGB channels and learned channels are different

RGB means red, green, and blue. An RGB image has three input channels: each channel is a grid of one physical color measurement. A red channel value has a camera-color interpretation before the network sees it.

A learned feature channel is an output grid produced by a kernel and activation. It may respond to an edge, texture, or combination discovered during training. An input RGB channel has a fixed camera-color meaning; a hidden channel does not. Spatial resolution is the height and width of a grid. A receptive field is the input region that can influence one later activation; stacking local layers makes that region larger.

See the field grow. Assume stride 1 (move the kernel one cell at a time) and no padding (add no border cells). The red outline marks the input pixels that can affect one deeper response. 4. The backbone idea

A backbone is the feature-extracting part of a vision network. It turns the input image into increasingly useful feature maps. A later task-specific component reads those maps to produce the requested output. For object detection, that output includes object classes and locations, but this lesson focuses on the shared feature computation.

The backbone is not a magic “understanding” box. It is a stack of weighted sums, activations, and spatial operations whose parameters were adjusted using data. The feature maps are useful only insofar as they support correct predictions on relevant new images.

Final challenge · same edge, new position

A cube moves from the center of the camera image to the left edge. The detector should still respond to its vertical edge, but a deeper unit should combine several local responses before deciding whether the shape is useful. Which explanation best fits the layered model?

Worked reveal and rubric

The field explanation is the right one. Weight sharing lets the same local kernel look for an edge wherever it appears; stacked layers let a deeper response depend on a larger input region. The response channel is learned evidence, not the fixed red camera channel, and one top-left arithmetic result cannot represent the whole image.
