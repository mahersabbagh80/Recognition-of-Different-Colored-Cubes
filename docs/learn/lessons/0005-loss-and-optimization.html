Loss and optimization

A loss turns disagreement into a number; a gradient suggests a local direction; an optimizer repeats controlled updates.

15–20 minutes including practiceOne real gradient stepLearning-rate visualizer

Your goal: trace one training update from a prediction error to evidence about the robot’s behavior.

1. Why training needs a number

Imagine a training log that says the model predicted 3 when the target was 6. The model needs one signal that says how bad that miss is and which small parameter change could make the next prediction closer. Loss supplies the first signal; a local slope supplies the second.

A model maps inputs to predictions. Its parameters are adjustable numbers. In the small model below, a weight multiplies an input measurement (a feature), and a bias adds an offset.

A forward pass runs an input through the model to make a prediction. A loss function assigns a numeric penalty to that prediction and its target, the desired answer. Lower loss means better according to that chosen penalty. For a toy one-number prediction, use squared error: L = (ŷ − y)², where ŷ is the prediction and y is the target. Squaring makes larger misses count more.

Before using the word gradient, look at the shape of a toy loss. Let J(w) = (w − 3)². At w = 0, nudging w to the right lowers J, so the local slope is negative. In one dimension the gradient is that slope; with many parameters it is the collection of one local slope per parameter. Here w is one adjustable parameter and J names this one-parameter loss. A tangent is a straight line following the curve’s local slope. For a concrete nudge, J(0) = 9 and J(0.1) = 8.41: a small increase in the parameter lowers loss.

Gradient descent moves parameters in the direction that locally lowers loss. “Descent” means downhill here; it does not promise the global best point.

Central mental modelForward pass → prediction → loss → gradients → parameter update. Repeat over many examples, then check behavior on data that did not update the parameters.

2. One actual numeric gradient step

Use a one-feature linear model, meaning a weighted sum plus a bias, ŷ = w×x + b. The symbol w is a weight, b is a bias, and x is the input feature. Start with x = 2, target y = 6, weight w = 1, bias b = 1, and learning rate η = 0.1. A learning rate is the multiplier controlling how far one update moves. The symbol η is the Greek letter eta; here it names that step-size setting.

First, the prediction is ŷ = 1×2 + 1 = 3. The error is ŷ − y = 3 − 6 = −3, so the squared loss is L = (−3)² = 9. For this simple model, the gradient with respect to the weight is ∂L/∂w = 2(ŷ−y)x = 2(−3)(2) = −12, and the gradient with respect to the bias is ∂L/∂b = 2(ŷ−y) = −6. The expression ∂L/∂w means the local slope of loss when only the weight changes; ∂L/∂b does the same for the bias. These are the slope formulas for this particular model and squared loss.

Apply new parameter = old parameter − η×gradient. Thus w′ = 1 − 0.1×(−12) = 2.2 and b′ = 1 − 0.1×(−6) = 1.6. The prime mark ′ means “after the update.” The new prediction is ŷ′ = 2.2×2 + 1.6 = 6.0, and the new squared loss is 0 for this one example. This exact improvement is a property of the tiny example, not a promise about a neural network or a detector.

Before changing the step: if η = 0, multiplying either gradient by zero makes the update zero, so both parameters stay fixed. Increasing η makes the same update larger. A step can go past a low-loss point; this is overshooting. For the worked example, η = 0.10 reaches loss 0, while η = 0.30 gives prediction 12 and loss (12−6)² = 36, worse than the starting loss 9.

3. Backpropagation and optimizers

Backpropagation, short for backward propagation of errors, sends the loss information backward through the operations that produced the prediction. It combines local rates of change to calculate one gradient for each parameter.

An optimizer uses those gradients to update parameters. Plain gradient descent uses the equation above; AdamW is another optimizer. A batch is the group of examples used for one update, and an epoch is one complete pass through the training set. These are training mechanics, not evidence that the final detector works in the room.

The learning rate controls step size, not model quality. A rate that is too large can overshoot or oscillate; one too small can make progress slow. A decreasing training loss is evidence about the chosen objective, not proof of reliable deployment.

4. Loss versus metric

A metric is a reported measurement of performance that helps people judge whether a system serves its task. A metric may be useful for selection or communication, but it need not be the differentiable loss used for every update; differentiable means that local slopes can be calculated for a small parameter change. Accuracy is the fraction of decisions that are correct. Precision is the fraction of accepted predictions that are correct. Recall is the fraction of real targets that were found. For a safety-relevant detector, missing a cube and raising a distractor may have different costs, so one metric rarely tells the whole story.

5. Applied to our cubes

Fine-tuning continues training a saved model. Hard negatives are non-target examples that resemble targets, such as colored packaging that is not a cube.

Current code: the hard-negative fine-tune defaults to a starting learning rate of 0.0005 and passes optimizer="AdamW" explicitly. An optimizer is the rule that turns gradients into parameter updates. The opening recipe comment says “AdamW (auto),” but the executable call is explicit; do not describe this script as asking the library to choose the optimizer.

Selected arguments from the training call:

lr0=args.lr0,
optimizer="AdamW",

The model.train call receives the --lr0 argument, whose default is defined in the same file and can be overridden when launching the script. The toy update w′ = w − η∂J/∂w teaches direction and step size; it is plain gradient descent. AdamW also uses recent gradient history to rescale updates and applies weight decay, a separate small pull of parameters toward zero. Therefore the toy numbers do not predict the exact sequence of AdamW updates.

Proposed improvement: record the effective settings, compare choices on validation data and assess the selected result on a separate untouched test capture, and promote a checkpoint only after recall and false positives are reviewed.

Final challenge · one more update

Use the same toy model from this lesson with x = 2, y = 6, w = 1, and b = 1, but choose η = 0.05. Which result follows after one gradient update?

Worked reveal and rubric

Start with gradients ∂L/∂w = −12 and ∂L/∂b = −6. Subtract 0.05 times each: w′ = 1 − 0.05(−12) = 1.6 and b′ = 1 − 0.05(−6) = 1.3. Then ŷ′ = 1.6×2 + 1.3 = 4.5 and L′ = (4.5−6)² = 2.25, lower than the starting loss 9.
