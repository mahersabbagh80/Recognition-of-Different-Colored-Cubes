Read the output

output0: [batch, fields, candidates] = [1, 7, 8400]
out[0]: [7, 8400]
transpose: [8400, 7]
row: [cx, cy, width, height, blue_score, green_score, red_score]

8400 = 80×80 + 40×40 + 20×20. These are candidate positions, not final detections. This fused output has no separate objectness field.

Decoder order

  1. Transpose to one candidate per row.
  2. Choose the largest of the three class scores and its class ID.
  3. Discard rows below the confidence threshold.
  4. Convert xywh to xyxy.
  5. Undo letterbox padding and scale.
  6. Clip to the original camera-frame bounds.
  7. Run NMS separately for each predicted class.
  8. Return class name, score, and camera-frame box.

Do not transfer blindly

Traditional YOLOv5 examples such as `(1,25200,85)` do not describe this artifact. Re-check shape, field order, score semantics, and decoder behavior whenever the export changes.
