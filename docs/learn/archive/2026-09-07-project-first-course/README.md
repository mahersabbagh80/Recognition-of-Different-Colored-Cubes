# Colored-cube perception learning workspace

Open [`index.html`](index.html) for the learner-facing course entrance.

The workspace is intentionally located at `docs/learn/` because its lessons and references depend on this repository’s code, model artifacts, and measured evaluation evidence. `MISSION.md` defines the learning outcome, `RESOURCES.md` defines trusted sources, and evidence-based learner state belongs in `learning-records/`.
