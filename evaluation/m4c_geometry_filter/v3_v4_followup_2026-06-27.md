## 0. How this run was produced

Each V3 distractor and the V4 empty scene were captured via the same
sync RGB+depth harness used in M4c1 (`scripts/capture_rgb_depth_sync.py`
on the Jetson, md5 verified against dev PC), pulled to the dev PC,
run through YOLOv5 ONNX inference (`scripts/m4c_yolo_inference.py`,
conf=0.25, iou=0.45), then the Phase 1 geometry filter
(`scripts/m4c_geometry_filter.py`) with the M4c1 v2-only parameter
set **passed explicitly**:

```
--raised-mm 30 --min-raised-frac 0.20 \
--max-planar-top-stddev-mm 30 --max-ratio 1.2 \
--inset-px 1 --annulus-outer-px 15
```

The `--inset-px 1 --annulus-outer-px 15` flags are critical — without
them the script defaults (4 and 30) apply, which yield a different
behavior on the gray-cloth annulus floor depth (see M4c1 follow-up
LOGBOOK entry 2026-06-27). The orchestration script
`scripts/m4c_v3v4_run.sh` passes them automatically.

All 30 frames per set SHA-256 verified against the sidecar JSON.
Pipeline orchestrated by `scripts/m4c_v3v4_run.sh`.
